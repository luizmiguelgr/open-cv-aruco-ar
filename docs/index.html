AR Educacional

Aplicação de Realidade Aumentada em C++ que usa marcadores ArUco para exibir modelos 3D associados a matérias escolares (Biologia, História, Geografia).

C++17 OpenCV 4.x ArUco POO 2º Período
Código no GitHub Relatório (PDF) Vídeo

O que faz

O sistema captura vídeo da webcam em tempo real, detecta marcadores fiduciais ArUco impressos em papel e, sobre cada um, renderiza um modelo 3D em wireframe junto com uma legenda da matéria correspondente. É uma ferramenta didática: cada marcador vira uma "carta" de uma disciplina.

Biologia

Marcadores 0 e 1

Crânio humano (modelo OBJ) e formas geométricas. Cor tema: verde.

História

Marcador 2

Modelo de fuzil M4A1 representando tecnologia militar moderna. Cor tema: laranja.

Geografia

Marcadores 3 e 4

Rocha low-poly representando ciclo geológico. Cor tema: azul.

Principais recursos

  • Detecção em tempo real de múltiplos marcadores ArUco com estimação de pose 3D.
  • Renderização wireframe de modelos .obj arbitrários (parser próprio).
  • HUD com barra colorida da matéria, título e descrição.
  • Configuração externa em conteudos.txt — adicionar modelos sem recompilar.
  • Arquitetura orientada a objetos com herança, polimorfismo e composição.
  • Extensível: novas matérias entram com uma única subclasse.

Arquitetura

O código é dividido em três camadas:

Geometria

Objeto3D (abstrata)

Cubo, Piramide, ModeloOBJ. Cada classe sabe se projetar com cv::projectPoints e desenhar suas arestas.

Educação

ConteudoEducacional (abstrata)

ConteudoBiologia, ConteudoHistoria, ConteudoGeografia. Cada conteúdo compõe um Objeto3D* e associa uma Materia.

Orquestração

GerenciadorConteudo + ConfigLoader

Mapeia ID do marcador ArUco para o conteúdo correspondente. Lê o conteudos.txt no início.

Diagrama simplificado:

   Objeto3D (abstrata)             ConteudoEducacional (abstrata)
       ▲                                      ▲
       │                                      │
   Cubo, Piramide,                  Biologia, Historia,
   ModeloOBJ                        Geografia
       ▲                                      │
       │                                      │ contém um (composição)
       └──────────────────────────────────────┘

   GerenciadorConteudo  ──── map<int, ConteudoEducacional*>
            ▲
            │ popula
   ConfigLoader ◀── conteudos.txt

Conceitos de POO aplicados

  • Herança: duas hierarquias paralelas (Objeto3D e ConteudoEducacional).
  • Polimorfismo: chamadas como conteudo->renderizar() e modelo->desenhar() resolvidas em tempo de execução via vtable.
  • Composição: ConteudoEducacional contém um Objeto3D* em vez de herdar dele — qualquer matéria com qualquer geometria.
  • Abstração: métodos virtuais puros forçam subclasses a implementarem desenho e curiosidade.
  • Encapsulamento: campos private/protected com getters públicos.
  • Padrões de projeto: Strategy (geometrias), Factory (criação a partir de string), Template Method (esqueleto de renderizar).
  • Ponteiros e referências: ponteiros para classe base habilitam polimorfismo; destrutores virtuais garantem liberação correta de memória.

Compilar e rodar

cmake -B build -S .
cmake --build build --config Release
.\build\Release\aruco_ar.exe

Requer OpenCV instalado via vcpkg (vcpkg install opencv4). Imprima os marcadores ArUco 0–4 (gere com generate_markers.exe) e aponte a webcam para eles.

Como expandir

Para adicionar um novo modelo, basta editar conteudos.txt:

Geografia | 5 | obj | vulcao/vulcao.obj | 0.02 | 0,0,0 | 0,0,0 | 200,80,40 | Vulcão | Tipo de relevo

Para adicionar uma nova matéria (ex.: Arte), basta criar uma subclasse de ConteudoEducacional em 2 arquivos.
